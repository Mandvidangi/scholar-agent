# ScholarAgent

ScholarAgent is a multi-agent research paper assistant that helps users upload research papers, extract text, ask questions, generate literature reviews, find research gaps, and validate citations using Agentic AI and RAG.

## Features Planned

- PDF upload
- PDF text extraction
- RAG-based paper Q&A
- Citation-backed answers
- Literature review generation
- Research gap finder
- Hallucination checker agent
- Export to report

## Tech Stack

- Python
- FastAPI
- PyMuPDF
- FAISS
- LangGraph
- Streamlit/React
- Docker
